## Pierwsze piec zadan - podstawowe typy danych
1. Program przeliczajacy wielkosc kata wyrazona w stopniach na radiany i wyswietlajacy ja na ekranie
2. Program wczytujacy trzy liczby calkowite oraz obliczajacy ich sume, srednia arytmetyczna i srednia harmoniczna z liczb calkowitych
3. Program obliczajacy objetosc kuli oraz stozka
4. Program obliczajacy czy rok jest przestepny
5. Program obliczajacy rozwiazania rownania kwadratowego i liniowego
