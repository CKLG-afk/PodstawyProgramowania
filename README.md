# PodstawyProgramowania
Zestaw programów wykonanych na I semestrze studiów na przedmiocie "Podstawy Programowania"

## Zakres materiału
* Podstawowe typy danych 
* Instrukcje: instrukcja warunkowa if, if/else, switch
* instrukcje pętli for, while do/while
* instrukcje break, continue, return.
* Dynamiczny przydział pamięci.
* Wskaźniki.
* Typy złożone: tablice, struktury, unie.
* Funkcje: - przeciążone - rekurencyjne. - z parametrem tablicowym.
* Tablice znakowe.
* Operatory bitowe.
* Przestrzenie nazw, zakres i czas trwania zmiennych.
* Plikowe operacje wejścia.
